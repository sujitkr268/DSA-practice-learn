## ⚡ Approach

For each problem, the goal is not simply to get an accepted submission.

I focus on understanding:

1. **Problem statement**
2. **Brute-force approach**
3. **Better approach**
4. **Optimal approach**
5. **Time & space complexity**
6. **Edge cases and common mistakes**
7. **Alternative approaches when applicable**

The objective is to understand **why the solution works**, rather than memorizing code.

## 🔄 LeetSync

This repository uses **LeetSync** to automatically synchronize accepted LeetCode submissions with GitHub.

Whenever a solution is successfully submitted on LeetCode, it can be automatically added to this repository, keeping the practice history organized.
